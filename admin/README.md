# Noesis — Admin

App web interne (Next.js) pour relire et publier le contenu de cours généré par IA avant qu'il n'atteigne les élèves. Voir le README à la racine du repo pour les instructions de setup complètes (Supabase, edge function, création d'un compte admin).

```
npm install
cp .env.example .env.local
npm run dev
```
